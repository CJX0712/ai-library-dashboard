# ai-library-dashboard

AI 资料库总览看板 —— 单文件 HTML，零依赖零构建，双击即用。

## 内容

对「AI 大全 · 人工智能与机器学习综合知识库」的结构化总览：

- 领域全景（数学基础 → 三大范式 → 深度学习 → 大模型）
- 各方法谱系卡片：直觉 / 数学核心 / 伪代码 / 复杂度 / 经典论文 / 常见坑 / 可验证不变量
- forge 系列手写实现索引（纯 JS 单文件，浏览器内一键自检）

## 用法

无需安装、无需联网：

```bash
# 直接打开
start index.html

# 或起个本地服务
python -m http.server 8000
```

## 不变量 · Verifiable Invariants

每份 forge 实现都带浏览器内自检（Node 无头亦可），覆盖：

- 梯度检验：解析梯度 vs 中心差分，相对误差 ~1e-7
- 概率归一：责任度行和为 1、混合权重和为 1
- 矩阵性质：正交 `QᵀQ=I`、对称半正定、Jacobi 残差 `‖Av−λv‖≈1e-15`
- 结构最优：SVD 秩-k 截断最优性、 Bellman 残差 → 0
